API Drift Engine

Active outbound vendor risk engine — polls external vendor OpenAPI specs, diffs, correlates breaking changes with internal telemetry, deduplicates alerts, and automates remediation.

Deploy to Render View on GitHub Live Demo

Features

🔍

Scheduled Polling

Cron-based polling of vendor OpenAPI 3.0/3.1 specs. Detects changes the moment they're published.

⚠️

Breaking Change Detection

Directional compatibility diffs with rule-based evaluation — request, response, and webhook changes.

📈

Telemetry Correlation

Cross-references changes against internal service dependencies. Consumed endpoints get CRITICAL escalation.

🔔

Multi-Channel Alerts

Dispatch to Jira, Slack, and PagerDuty. Batch mode aggregates changes into single notifications.

🔑

Fingerprint Deduplication

SHA-256 fingerprints with state machine (NEW → ACTIVE → RESOLVED). No duplicate alerts.

🔒

SSRF Protection

Blocks loopback, link-local, and RFC 1918 ranges. AES-256-GCM encryption for vendor API tokens.

Pipeline Architecture

[Scheduled Cron / Webhook Trigger] | v +----------------------------+ | Ingestion Worker Service | <-- (Egress Proxy / SSRF Guard) +-------------+--------------+ | Downloads Raw Spec v +----------------------------+ | SHA-256 Hashing & Cache |--> (If Unchanged: Halt Execution) +-------------+--------------+ | If Changed v +----------------------------+ | OpenAPI 3.0/3.1 Parser | | & Dereferencing Engine | +-------------+--------------+ | Normalized AST v +----------------------------+ | Directional Compatibility | | & Rule Evaluation | +-------------+--------------+ | Raw Detected Changes v +----------------------------+ | Usage Correlation Engine | <-- (Telemetry Registry) +-------------+--------------+ | Impact-Weighted Diffs v +----------------------------+ | Fingerprint Deduplication | | & Alert Dispatcher |--> [ Jira ] [ Slack ] [ PagerDuty ] +----------------------------+

Quick Start

Prerequisites: Java 21, Maven 3.9+ (or Docker)

Run with H2:

./mvnw spring-boot:run -Dspring-boot.run.profiles=h2

Register a vendor:

curl -X POST http://localhost:8080/api/v1/vendors \ -H "Content-Type: application/json" \ -H "Authorization: Basic $(echo -n 'admin:admin' | base64)" \ -d '{"vendorName":"Stripe","specUrl":"https://raw.githubusercontent.com/stripe/openapi/master/openapi/spec3.json","cronExpression":"0 0 */6 * * ?","isActive":true}'

Trigger a diff:

curl -X POST http://localhost:8080/api/v1/diffs/trigger/1 \ -H "Authorization: Basic $(echo -n 'admin:admin' | base64)"
